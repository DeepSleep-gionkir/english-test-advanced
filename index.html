  2. 서술형은 문제의 단어·어순·생략 조건을 지켜 쓰세요. 대소문자, 불필요한 앞뒤 공백, 연속 공백, 문장 끝의 마침표·물음표·느낌표와 답 구분용 / 앞뒤 공백는 채점에 반영하지 않습니다. 철자와 단어 순서는 채점합니다.
  3. 축약하지 말라는 조건이 있으면 did not, could not 등으로 쓰세요. 답에 문항 번호나 따옴표를 덧붙이지 마세요.
  4. 전 문항 동일 배점입니다. 맞힌 문항 수 ÷ 150 × 100을 소수 첫째 자리까지 표시합니다. 미응답은 오답으로 처리하며 부분 점수는 없습니다.
  5. used to의 부정문·의문문은 학교 시험에서 쓰는 did not use to / Did … use to 표기를 기준으로 합니다. so … that은 정도·결과(~해서 …하다)만 다룹니다. used to의 부정문·의문문은 4문항에만 포함됩니다.
  6. 답안은 이 브라우저에 자동 저장됩니다. 답안 저장을 누르면 현재 답안과 진행 상태를 이 브라우저의 로컬스토리지에 즉시 저장합니다. 같은 기기·브라우저에서 같은 웹사이트를 다시 열면 이어서 풀 수 있습니다. 다른 기기와 동기화되지 않으며, 브라우저의 사이트 데이터를 삭제하면 저장된 답안도 지워집니다.
